## Resumen en una línea por módulo

- **Hoy** — agenda diaria de tomas con estados pendiente / atrasada / administrada / omitida.
- **Residentes** — fichas con alergias, diagnósticos, contacto, medicamentos y cuidados.
- **Bitácora** — historial filtrable de cuidados y medicación.
- **Ajustes** — cuidador en turno, recordatorios diarios, datos de ejemplo.
